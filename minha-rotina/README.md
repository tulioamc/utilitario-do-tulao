# Minha Rotina

Aplicativo PWA para o período de 23/11 a 13/12/2026.

- Registros locais no navegador (localStorage).
- Exportação/importação de backup JSON.
- Calendário semanal, registro de estudo e treinos.
- Para instalar no iPhone: abrir pelo Safari e usar Compartilhar > Adicionar à Tela de Início.

Os dados permanecem neste aparelho/navegador. Exporte backups regularmente.
